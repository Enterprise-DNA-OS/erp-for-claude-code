# cancel-order

Read the order first. Only untouched draft or open orders can be cancelled. Partially fulfilled orders require a documented correction.

Run `npm run erp -- cancel-order <order> "reason"`. Exact argument details: docs/cli.md. Resolve ambiguous names by listing candidates. Never send, pay or delete.
