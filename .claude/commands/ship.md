# ship

Record only goods physically dispatched. Read stock and the remaining quantity first. A reference can be used once.

Run `npm run erp -- ship <sales-order> <line-number> <quantity> --event=<unique-dispatch-reference>`. Exact argument details: docs/cli.md. Resolve ambiguous names by listing candidates. Never send, pay or delete.
