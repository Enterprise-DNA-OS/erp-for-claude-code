# log-cost

Record a documented job cost, excluding tax, in the configured currency. Use a unique evidence reference.

Run `npm run erp -- log-cost <job> <labour|materials|other> <amount> "note" --event=<unique-reference>`. Exact argument details: docs/cli.md. Resolve ambiguous names by listing candidates. Never send, pay or delete.
