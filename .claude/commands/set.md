# Set

Read the record first. `npm run erp -- set <entity> <code-or-name> --field=value` updates descriptive fields, due dates, price defaults or evidence. It records before and after values. No code, currency, stock quantity, order kind or status may be changed this way. Use the transaction command for operational changes. Read docs/cli.md. Do not invent source evidence.
